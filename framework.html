Methodology

Framework.

Five layers. One formula. Five verdicts. Three idea classes. The framework is the asset — not any single idea. Personal variables are declared transparently so others can substitute their own.

Idea Classification

Three Classes

Not all ideas fit the same analytical lens. Classification is done before analysis begins — not chosen to make the idea look better.

CLASS A — VIABLE

From the Start

Clears NRR/OPEX ≥ 1.5× within ramp period. Standard five-layer analysis. Burn ceiling applies. Verdict: Build / Test / Park / Kill.

CLASS B — INVESTMENT

Horizon Ideas

Phase 1 burn tracked. Phase 2 formula applied. ROI/Payback layer required. Both ratio floor and recoup rule must be satisfied independently.

CLASS C — ENRICH

Hobby / Enrichment

Fails financial floor or burn ceiling. Non-financial return declared. Loss ceiling and milestone trigger required. Verdict: Enrich.

The Hard Floor

Formula

NRR / OPEX ≥ 1.5  →  worth pursuing
Every idea must clear this independently
No exceptions. No narrative bias.
NRR

Gross Revenue minus COGS. What actually lands after the direct cost of producing and delivering one unit.

COGS

Anything directly tied to producing one unit. When automation replaces a human task, cost converts from OPEX to COGS — improving ratio dynamics significantly.

OPEX

Hours consumed × $17 CAD/hr. Ontario minimum wage. The most accessible zero-friction alternative for available hours. OPEX = $0 in months where no output is produced.

Growth Component
Growth Score = (Market Size / CAC) × Scalability Modifier
0.5 = linear  |  1.0 = moderate  |  2.0 = high leverage
Analysis Structure

Five Layers

01

Concept

What is it. Where from. What problem. No selling.

02

Market

Who buys this. How many. How reachable. Timing.

03

Economics

Unit economics. Margin. Ratio at three scales.

04

Execution

Hours to first dollar. Capital. Automation timeline.

05

Risk

Legal. Competitive. Platform. Personal fit.

LAYER 01

Concept

Honest description before any analysis begins. No selling. No optimistic framing. Define scope clearly so analysis is not contaminated by narrative bias.

  • Plain description — what it is and how it works
  • Origin — where the idea came from
  • The problem or desire it addresses
  • What this idea explicitly is not
  • Class assignment — A, B, or C — stated before proceeding
LAYER 02

Market

Viable unit economics in a market that is too small, too saturated, or too hard to reach is still a failing business.

  • Total Addressable Market in dollars, not people
  • Serviceable Addressable Market
  • Year 1 conservative target — cited, not assumed
  • Customer Acquisition Cost and channel
  • Timing — growing, saturating, or shifting
  • Competition density and defensibility
LAYER 03

Economics

The formula applied. Unit economics built bottom-up, projected at three scale points. Lifestyle threshold mapping connects dollar amounts to concrete life changes.

  • Revenue per unit and pricing rationale
  • Full COGS breakdown — every variable cost named
  • NRR/OPEX ratio at launch, steady-state, and scale
  • Automation conversion timeline with trigger conditions
  • Lifestyle threshold mapping
LAYER 04

Execution

What it actually takes to get to first dollar. Not best case — the honest effort required to launch and sustain.

  • Hours to launch — broken down by task
  • Capital required before first revenue
  • Skills gap — what needs to be learned or hired
  • Automation potential with NRR trigger conditions
  • Ongoing monthly load at steady state
LAYER 05

Risk

Risk assessment without catastrophizing or minimizing. What can kill this and how likely.

  • Legal and regulatory exposure
  • Competitive moat and replication speed
  • Platform dependency risk
  • Operational single points of failure
  • Personal fit through the build phase
The Output

Verdict

Not a sixth layer — the output of the five. A rating, supporting scores, and a plain English paragraph that stands alone.

Build

Clears 1.5×. Lift manageable. Risk contained. Start now.

Test

Clears on paper. Key assumptions unverified. Run cheapest possible test first.

Park

Viable model. Wrong timing or conditions. Document trigger for revisiting.

Kill

Does not clear 1.5×. No credible path. Recoup fails floor. Move on.

Enrich

Fails financial floor. Non-financial return declared. Loss ceiling required. Eyes open.
